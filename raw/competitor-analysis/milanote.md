# Milanote 横评报告

> 证据等级：B（官方页面/G2 评测），C（Reddit/第三方博客）
> 时效：2025年（Milanote 最新版本）
> 数据来源：milanote.com 官方、thedigitalprojectmanager.com、G2 Reviews、Storyflow 对比博客

---

## 一、产品定位

Milanote（同名澳大利亚公司，2017年创立）是一款**视觉化创意组织工具**，核心形态为"数字墙"（digital board）。不是传统意义上的写作软件，而是以**视觉化卡片 + 自由布局**方式管理创意、灵感和项目素材。主力用户：设计师、创意总监、编剧、电影制作人、营销团队。**Milanote 与写作软件最相关的使用场景是"写作前期的头脑风暴和素材收集"，而非实际写作过程本身。**

---

## 二、核心功能描述（证据等级 A/B）

### 2.1 Board（数字墙）
Milanote 的核心产品形态：
- 无限大的数字墙（Board），可在其中自由放置内容
- 支持拖拽排列，卡片可堆叠、分组
- Board 可创建多个，Milanote 支持组织（Organization）层级管理多个 Board
- 支持在 Board 中添加文字、图片、链接、颜色标签

> 证据：A — milanote.com 官方产品页

### 2.2 内容卡片（Cards）
Milanote 的基本内容单元：
- **Text Card（文字卡片）**：自由格式文字，适合笔记、灵感片段
- **Image Card（图片卡片）**：图片、截图、灵感图
- **Link Card（链接卡片）**：可保存网页链接，带缩略图预览
- **Column Card（列卡片）**：将卡片分组为列，适合任务管理
- **列表卡片**：待办事项列表风格

### 2.3 创意写作模板
Milanote 提供专门面向创意写作的模板：
- **Creative Writing Board**：故事板、角色卡片、情节线、场景规划
- **Screenplay / Storyboard**：编剧/导演的视觉化剧本规划
- **Mood Board**：氛围参考板

> 证据：A — milanote.com 官方 "Creative writing" 产品页

### 2.4 协作
- 支持多人实时协作（Real-time collaboration）
- 通过链接邀请，无需账号即可查看（编辑需注册）
- 评论和 @提及功能

> 证据：A — Milanote 官方

### 2.5 导出
- 可导出为 PDF、图片
- 可复制单个卡片内容为文本
- **不支持导出为标准文档格式**（如 Word、ePub）

### 2.6 价格
| 层级 | 价格 | 内容 |
|------|------|------|
| Free | $0 | 100 张卡片/图片，3 个 Board |
| Pro | $12/月 | 无限卡片，100 个 Board |
| Organization | 定制 | 团队协作，无限 Board，SSO |

## 三、AI 功能现状

### 3.1 内置 AI
**无 AI 功能。** Milanote 官方确认：Milanote 完全不包含任何 AI 功能，任何定价层级均无。

### 3.2 第三方 AI 集成
- 用户可将 ChatGPT/Claude 等 AI 输出复制为 Text Card 粘贴到 Board 上
- 无原生 AI 集成

### 3.3 AI 能力总结
**零 AI。** Milanote 是六款竞品中唯一完全不包含任何 AI 功能的工具（与 Scrivener 的"无 AI 但接受外部 AI"不同，Milanote 是纯粹的视觉化组织工具）。

## 四、结构化写作支持

| 维度 | 支持情况 | 备注 |
|------|---------|------|
| 大纲（多级标题） | ❌ 无大纲概念，Board 是自由布局 | |
| 章节（独立节点） | ❌ 无章节概念 | |
| 脚注 | ❌ 无 | |
| 引用 | ❌ 无 | |
| 备注/批注 | ⚠️ 可在卡片上写文字，但非批注 | |
| 图片/图表 | ✅ 核心功能，支持丰富 | |
| 研究资料收集 | ✅ 强项——Milanote 非常适合收集参考图片和灵感素材 | |
| 写作输出 | ❌ Milanote 不生成可导出的文档 | 只能复制文字内容 |

**结构化写作综合评估：极弱。** Milanote 是"写作前期的创意组织工具"，不是写作工具。它适合收集灵感、规划故事结构（视觉化），但完全无法替代任何一款专业写作软件。

## 五、已知局限（证据等级 B/C）

### 5.1 非写作工具（根本定位问题）
Milanote 的核心局限不是功能缺失，而是**它根本不是写作工具**。它解决的是"灵感收集"问题，不是"写长文"问题。

### 5.2 无 AI（2025年严重劣势）
- 六款竞品中唯一完全没有 AI 的产品
- 在 AI 写作工具爆发的背景下，零 AI 是重大竞争劣势

### 5.3 协作局限性
- **无实时编辑光标**（对比 Notion/Lex 的实时协作）
- 仅支持基础的评论和@提及

### 5.4 导出限制
- 无法导出为标准化文档格式（Word/ePub/PDF）
- 仅能以图片或 PDF 快照形式导出 Board

### 5.5 免费版限制
- Free Plan 仅 100 张卡片和 3 个 Board
- 创意写作用户很快达到上限

## 六、对 WritCraft 的意义

| 维度 | 启示 |
|------|------|
| 视觉化素材收集 | Milanote 证明"写作前期需要视觉化素材收集"，WritCraft 可在 IDE 内集成轻量级素材收集板 |
| 卡片式 UI | Milanote 的卡片概念可启发 WritCraft 的章节/场景卡片管理 |
| 创作者生态 | 设计师/编剧/导演等创意专业人士是重要用户群，WritCraft 应关注这类用户需求 |
| 非写作工具 | Milanote 完全不能替代任何一款竞品，证明"视觉化灵感工具"和"写作工具"是不同赛道 |
| AI 缺失 | Milanote 的零 AI 再次说明，2025 年及以后，任何创作工具没有 AI 都会被边缘化 |
| 协作 | Milanote 的轻量级协作模式（链接邀请、评论）可借鉴 |

**核心结论：Milanote 是"创意组织工具"，而非"写作软件"。** 其与 WritCraft 的关系更像是"写作前期的灵感收集板"而非直接竞品。WritCraft 若能内联轻量级灵感收集板（类似 Milanote Board），可形成差异化优势。
