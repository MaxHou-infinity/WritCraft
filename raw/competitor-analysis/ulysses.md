# Ulysses 横评报告

> 证据等级：A（官方页面），B（App Store 评测/媒体评测）
> 时效：2025年（Ulysses 最新版本，支持 macOS/iOS）
> 数据来源：ulysses.app 官方、App Store、TechCrunch/Mashable/The Guardian 评论

---

## 一、产品定位

Ulysses（ Ulysses GmbH，德国，2003年创立）是 Apple 生态下最知名的"纯写作"应用，定位为**专业长文写作工具**，尤其擅长书籍、日记、博客文章。获得 Apple Design Award（多次），在 Apple 生态内口碑极高。**核心哲学：标记式（Markup-based）、无干扰、纯文字创作。**

---

## 二、核心功能描述（证据等级 A/B）

### 2.1 统一 Library（图书馆）
- 所有文本存储在 Ulysses 的统一 Library 中
- 支持 Project（项目） > Group（分组） > Sheet（文本）三级组织
- Library 界面：左侧边栏按项目/群组分类，右侧预览
- 支持智能过滤器（Smart Filters），按标签/关键词自动分类

> 证据：A — ulysses.app 官方产品页

### 2.2 标记式编辑器（Markup-based Editor）
- 纯文本编辑，格式通过 Markdown 语法控制（## 标题、**粗体** 等）
- **分心模式**（Focus Mode）：隐藏所有界面元素，仅保留当前段落
- 语法高亮（Syntax Highlight）：iA Writer 同款，名词/动词/形容词等词性着色
- 实时预览（Live Preview）：Markdown 渲染效果即时显示
- 无需鼠标，键盘完成所有格式化操作

> 证据：A — Ulysses 官方："Its pleasant, focused writing experience, combined with effective document management, seamless sync, and flexible export"

### 2.3 项目管理（书籍/长文）
- 适合书籍写作：可将整本书分解为多个章节（Sheet）
- 支持设定字数目标（Goals）和截止日期（Deadlines）
- 统计面板（Statistics）：追踪每日/每周/每月写作字数
- 灵感收集（Library 中可存放图片和笔记）

> 证据：A — Ulysses 官方功能页

### 2.4 导出系统（Export）
Ulysses 的导出是其强项：
- **PDF**：可自定义样式（书籍、信件、学术论文等预设）
- **Word / DOCX**：保留格式的 Word 文档
- **ePub**：电子书格式，含目录
- **HTML**：网页格式
- **博客发布**：原生支持 WordPress、Ghost、Medium、Micro.blog
- 所有导出均通过 Ulysses Style Sheet（ULSS）控制格式

> 证据：A — Ulysses 官方

### 2.5 语法与风格检查（Built-in Proofreader）
- 20+ 语言的语法和风格检查
- 建议包括：大小写、标点、冗余、风格等
- 逐条建议呈现，接受/拒绝操作

> 证据：A — Ulysses 官方功能说明

## 三、AI 功能现状

### 3.1 内置 AI
**无原生 AI 功能。** Ulysses 没有内置 AI 写作助手。

### 3.2 Apple Intelligence 集成
- Ulysses 支持 macOS/iOS 的 Apple Intelligence（系统级 AI）
- 用户可选中文字后通过"写作工具"（Writing Tools）调用 ChatGPT（需主动开启 ChatGPT extension）
- 这不是 Ulysses 自有 AI，而是苹果系统的 AI 能力

> 证据：A — Ulysses 官方帮助："Writing Tools requires macOS 15.1+ or iOS 18.1+"

### 3.3 收费模式
- **平台**：仅 macOS/iOS（无 Windows/Linux）
- **订阅制**：Ulysses 仅有订阅制（iCloud Sync 需要），约 $5.99/月或 $49.99/年
- **买断**：2023年之前有买断制，但已下架
- 免费试用：全功能免费试用期

> 证据：A — App Store Ulysses 页面

### 3.4 AI 能力总结
Ulysses **刻意保持零 AI**——与 Scrivener 类似，Ulysses 坚持纯写作工具定位，不内置任何 AI 生成能力。用户可通过系统级 Apple Intelligence 获得基础辅助，但无深度 AI 写作集成。

## 四、结构化写作支持

| 维度 | 支持情况 | 备注 |
|------|---------|------|
| 大纲（多级标题） | ✅ Markdown H1-H6，层级丰富 | |
| 章节（独立节点） | ✅ Sheet 级别组织，一个 Sheet = 一章/一节 | 适合长文 |
| 脚注 | ✅ Markdown 脚注语法支持 | |
| 交叉引用 | ❌ Ulysses 不支持跨 Sheet 引用 | 硬伤 |
| 备注/注释 | ❌ 无批注功能（但 Sheet 内可写注释文本） | |
| 图片 | ✅ 支持插入图片（但无图文并排布局） | |
| 研究资料内联 | ⚠️ Library 可存图片/笔记，但与写作文本分离 | 非内联 |

**结构化写作综合评估：中等偏强。** Ulysses 的 Sheet 系统对书籍类结构化长文有良好支持，脚注支持也是其特色。但无交叉引用、无批注、无 Plan Mode。

## 五、已知局限（证据等级 B/C）

### 5.1 无 AI 能力（对 2025 年市场而言是硬伤）
- 无内置 AI，无 AI 写作辅助
- Apple Intelligence 是系统级集成，非 Ulysses 自身能力
- 无逐句 AI 修改、无 AI 续写、无 AI 反馈

### 5.2 仅 Apple 生态（平台锁定）
- 无 Windows 版本，无 Linux 版本
- 无法与 Android 或非 Apple 用户协作
- 对于跨平台团队不友好

### 5.3 订阅制争议
- 原有买断制取消，全部改为订阅
- 对于一次性购买用户造成不满

### 5.4 无交叉引用
- Ulysses Sheet 之间完全独立，无法相互引用
- 书籍写作中需要章节间引用时极不方便

### 5.5 无 Plan Mode
- Ulysses 无写作计划/大纲规划模式
- 写作者需自行在外部规划结构
