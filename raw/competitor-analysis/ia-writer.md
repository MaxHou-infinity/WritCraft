## 一、产品定位

iA Writer（Information Architects GmbH，瑞士-日本，2005年创立）是**专注 Markdown 的极简分心写作工具**。行业标准级的专注写作应用，屡获设计大奖（Red Dot Best of the Best 2025、iF Design Gold 2026、Apple Design Award Finalist 2025）。核心哲学：**"让写作回归文字本身"**——极简界面，分心模式，键盘优先，Markdown 导向。**iA Writer 是六款竞品中设计语言最成熟、但 AI 能力最保守的产品。**

## 二、核心功能描述（证据等级 A/B）

### 2.1 极简编辑器（Distraction-free Editor）
- 纯文本编辑，Markdown 格式
- **Focus Mode（分心模式）**：高亮当前句子/段落，背景淡化其他内容
- 逐行滚动阅读模式（Scroll Mode）
- 全屏写作模式
- 无工具栏、无菜单栏干扰（界面可全屏隐藏）

> 证据：A — iA Writer 官方 Features 页面

### 2.2 Syntax Highlight（语法高亮）
iA Writer 的标志性功能：
- 将文本按词性着色：名词（蓝）、动词（橙）、形容词（紫）、副词（绿）等
- 帮助写作者感知文章节奏和语言质量
- 支持英文、法文、德文、意大利文、西班牙文

> 证据：A — iA Writer 官方 Features 页面

### 2.3 Style Check（风格检查）
- 超越拼写检查的语义级风格建议
- 检测冗余表达、不精确用词、被动语态过多等
- 基于 iA 多年积累的写作规范数据库

> 证据：A — iA Writer 官方

### 2.4 Focus Mode（分心模式）
- 当前段落完全高亮，上下文文字降低透明度
- 可切换：一句模式（Sentence）/ 一段模式（Paragraph）
- 配合分屏（Split View）可同时查看两个文档

### 2.5 Markdown 导出与发布
- 导出为：PDF、Word（.docx）、HTML、ePub
- 博客发布：支持 WordPress、Medium、Substack、Ghost
- **Wikilinks**：`[[Page Name]]` 语法支持双链（iA Writer 特色）

### 2.6 多平台支持
- macOS（原生 App Store）
- iOS/iPadOS（App Store）
- Windows（原生 App）
- Android
- 四平台数据通过 iCloud/ Dropbox 同步

## 三、AI 功能现状

### 3.1 iA Writer 的 AI 哲学
iA Writer 官方对 AI 的态度：**谨慎、批判性使用**。iA Writer 认为 AI 是有用的写作伙伴，但需要严格限制其介入方式，避免"AI 替代写作"。

> 证据：A — iA 官方博客 "Writing with AI"（2023年11月28日）

### 3.2 官方 AI 功能
**无内置 AI 写作生成功能。** iA Writer 明确表示：iA Writer 本身不提供 AI 文本生成或重写功能。

### 3.3 iA Writer 的 AI 使用方式（批判性）
iA Writer 官方提出的 AI 使用框架：
- **AI 作为对话伙伴**：在写作前（pre-writing）用 AI 讨论构思，而非在写作中让 AI 生成内容
- **Think More, Not Less**：AI 适合帮助思考（Think More），不适合替代写作（Think Less）
- **AI 生成内容 = 合著，而非引用**：当 AI 生成内容混入人类写作时，是"合著"而非"引用"，归属问题复杂

> 证据：A — iA 官方博客 "Writing with AI"

### 3.4 iA Writer 的 AI 局限（官方立场）
1. **AI 无法理解**：AI 不理解它写的内容，无法判断好坏
2. **AI 会产生幻觉**：AI 写作包含幻觉和错误逻辑，需要人类严格审查
3. **AI 损害写作学习**：过度依赖 AI 会削弱写作者自身的语言能力
4. **混合文本归属问题**：AI 生成的文字混入人类文字后，无法区分，归属混乱

> 证据：A — iA 官方博客 "Writing with AI"

## 四、结构化写作支持

| 维度 | 支持情况 | 备注 |
|------|---------|------|
| 大纲（多级标题） | ✅ Markdown H1-H6，层级清晰 | |
| 章节（独立节点） | ❌ 无章节概念，纯单文档 | 核心局限 |
| 脚注 | ✅ Markdown 脚注语法支持 | |
| 交叉引用 | ✅ Wikilinks `[[Page Name]]` | iA Writer 特色 |
| 备注/批注 | ❌ 无批注功能 | |
| 图片 | ✅ 支持插入本地图片，Markdown `![]()` | |
| 多文档管理 | ❌ 无 Library/项目管理，纯单文档 | |

**结构化写作综合评估：弱。** iA Writer 是单文档线性写作工具，无章节管理、无多文档组织、无 Plan Mode，仅适合短文/单篇写作。其 Wikilinks 交叉引用是亮点。

## 五、已知局限（证据等级 B/C）

### 5.1 无章节/项目级结构（核心硬伤）
- 无 Library（Library 概念仅用于文件管理，非写作项目）
- 无多文档串联管理
- 书籍/长篇写作需要在外部工具管理章节结构

> 证据：B — Reddit r/iawriter 多位用户："iA Writer is great for one article at a time, but not for books"

### 5.2 无 AI（2025 年市场挑战）
- iA Writer 是六款竞品中 AI 整合最保守的
- 官方明确表示"不提供 AI 写作生成"
- 用户需自行拼接外部 AI 工具

### 5.3 无 Plan Mode
- 无写作计划/大纲规划功能
- AI 作为构思工具的使用方式需用户自行探索

### 5.4 纯买断制的双刃剑
- 优势：一次购买，终身使用，无订阅
- 劣势：无法持续获得新功能（大版本迭代才收费）

### 5.5 分心模式的局限
- Focus Mode 仅对"当前段落/句子"有效
- 无法进行项目级结构规划

## 六、对 WritCraft 的意义

| 维度 | 启示 |
|------|------|
| 极简哲学 | iA Writer 是"极简主义写作"的最高标准，WritCraft 需在功能丰富的同时保持核心界面的简洁 |
| Focus Mode | iA Writer 的分心模式是 WritCraft 写作界面设计的直接参考 |
| Syntax Highlight | 词性高亮是 WritCraft 可以借鉴的独特功能，帮助用户感知写作质量 |
| AI 批判性立场 | iA Writer 对 AI 的批判性思考（AI 不理解自己写的内容、AI 混合文本的归属问题）值得 WritCraft 认真对待，这正是"逐句 diff + 结论溯源"功能的价值来源 |
| Wikilinks | `[[Page Name]]` 双链语法是跨文档引用的优秀实现，WritCraft 应支持 |
| 买断制 | iA Writer 的纯买断制是一个独特的商业模式，WritCraft 可考虑买断 + 可选 AI 订阅的混合模式 |
| AI 缺失的市场机会 | iA Writer 在 AI 时代坚持"保守"策略，意味着它在专业 AI 写作市场正在失去竞争力——这是 WritCraft 的机会窗口 |
