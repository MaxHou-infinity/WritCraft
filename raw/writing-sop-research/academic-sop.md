# 学术综述 / 管理系统综述 SOP（结构化写作）

> **适用文体**：系统综述（Systematic Review）/ 元分析（Meta-Analysis）/ 叙述性综述（Narrative Review）/ 管理学报告  
> **字数区间**：5,000–30,000 字  
> **本质**：论文的论文——不是写自己的观点，而是系统性地整合、评估、合成现有研究的发现  
> **证据等级**：A（Cochrane 手册 / PRISMA 2020 指南 / UNC 图书馆系统综述 SOP / APA / MLA / Chicago 规范）

---

## 一、7 阶段 SOP 总览

| 阶段 | 名称 | 核心输入 | 核心输出 | 工具 | 耗时（参考） | 心法 |
|------|------|----------|----------|------|-------------|------|
| 1 | 灵感 | 研究空白；临床问题 | 研究问题（PICO） | PICO 框架；系统综述注册 | 2–4 周 | 问题先于检索 |
| 2 | 选题 | 研究问题 | 协议（Protocol）；注册 | PRISMA-P；Cochrane Protocol | 4–8 周 | 避免重复 |
| 3 | 大纲 | 协议；检索策略 | 文献检索结果；PRISMA 流程图 | PubMed/Embase/Cochrane；Zotero | 3–6 月 | 透明可复制 |
| 4 | 草稿 | 筛选结果；质量评估 | 数据提取表；偏倚风险评估 | Covidence/RevMan；ROB2 | 2–4 月 | 可重复性原则 |
| 5 | 修订 | 初稿 | 修订稿；敏感性分析 | 同行评审；统计再检验 | 2–4 月 | PRISMA 核对 |
| 6 | 编辑 | 修订稿 | 终稿；格式化 | 引用管理器；语言润色 | 1–2 月 | 规范一致性 |
| 7 | 发布 | 终稿 | 投稿；出版 | 期刊投稿系统 | 3–12 月 | 透明披露 |

## 二、每阶段详细 SOP

### 阶段 1：灵感（Inspiration — 发现研究空白）

**输入**：
- 领域内的系统综述注册库（PROSPERO / Cochrane Database）
- 最新 RCT 和系统综述（近 2 年）
- 临床/实践问题（对管理学：行业痛点 + 学术空白）

**输出**：
- 初步研究问题（使用 PICO 框架）：
  - **P**opulation（人群）
  - **I**ntervention（干预）
  - **C**omparison（对照）
  - **O**utcome（结局）

**系统综述 vs 叙述性综述选题差异**：
- 系统综述：需要完整检索策略 + 明确入排标准 → 适合有足够证据量的主题
- 叙述性综述：检索不必完整 → 适合新兴领域或探索性主题

**工具**：
- PRISMA 2020 检查表（下载：prisma-statement.org）
- PICO 问题生成器
- PROSPERO 注册查询

**耗时**：2–4 周

**心法**：
- "系统综述是对已发表研究的批判性综合——需要透明、可复制、有明确的方法论"（PRISMA 官方，A级）
- 问题决定一切——一个模糊的问题会导致一个无用的综述

---

### 阶段 2：选题（Topic & Protocol — 写协议）

**输入**：
- PICO 研究问题
- 初步检索（概念验证：确认有足够文献）

**输出**：
- **Protocol（研究协议）**：包含研究问题、入排标准、检索策略、数据提取计划
- **PRISMA-P 注册**（系统性综述注册，增加透明度和避免重复）
- **Cochrane Protocol**（如在 Cochrane 体系内）

**Protocol 核心内容**：
1. 研究背景（为什么这个问题重要？）
2. 研究问题（PICO 格式）
3. 入排标准（Inclusion / Exclusion Criteria）
4. 检索策略（数据库 + 检索词 + 日期限制）
5. 研究筛选流程（两人独立筛选 + 冲突解决）
6. 质量评估方法（ROB2 / GRADE）
7. 数据提取计划（变量 + 提取表）
8. 分析计划（描述性 vs 元分析）

**耗时**：4–8 周

**心法**：
- Protocol 写清楚是避免后期争议的关键——尤其是入排标准必须无歧义
- 系统综述的价值在于可重复性——Protocol 就是"方法论的合同"

---

### 阶段 3：大纲 / 检索（Search — 文献检索与筛选）

**输入**：
- Protocol
- 检索词列表

**输出**：
- **完整检索结果**（各数据库记录数）
- **去重后记录**（导入 Zotero / EndNote）
- **PRISMA Flow Diagram 数据**：
  - 识别阶段（Identification）：数据库检索记录数
  - 筛选阶段（Screening）：标题/摘要筛选后数量
  -  eligibility 阶段：全文评估后数量
  - 纳入阶段（Included）：最终纳入研究数

**检索数据库**（管理学建议）：
- 必检：PubMed/MEDLINE, EMBASE, Cochrane Library, Web of Science
- 管理学补充：Scopus, PsycINFO, Business Source Premier
- 灰色文献：OpenGrey, ProQuest Dissertations

**检索策略构建**：
1. 从 PICO 中提取关键词
2. 使用 Mesh 词（如适用）
3. 布尔逻辑组合（AND / OR / NOT）
4. 检索式保存记录（每步记录，便于复现）

**筛选流程**：
1. 两人独立标题/摘要筛选
2. 冲突解决（第三方仲裁）
3. 获取全文
4. 全文筛选（记录排除原因）
5. 质量评估（ROB2 for RCTs / Newcastle-Ottawa Scale for 观察性研究）

**工具**：
- Zotero / EndNote（文献管理）
- Covidence / Rayyan（筛选工具）
- PRISMA Flow Diagram（在线生成器：prisma-statement.org）

**耗时**：3–6 月（检索 + 筛选 + 质量评估）

**心法**：
- PRISMA Flow Diagram 是综述的"生产流程图"——必须透明记录每一步的决策和数量
- 筛选阶段的每一个排除都必须记录原因——方便读者评估偏倚风险

---

### 阶段 4：草稿（Draft — 数据提取与综合）

**输入**：
- 纳入研究列表
- 质量评估结果
- 数据提取表

**输出**：
- 初稿全文
- 描述性综合（表格呈现研究特征）
- 元分析结果（如数据足够且同质）

**综述结构**（按 PRISMA / IMRaD 格式）：

**引言（Introduction）**：
- 研究背景（问题的重要性）
- 研究现状（现有证据概述）
- 研究空白（为什么需要这项综述）
- 研究目的（PICO 格式）

**方法（Methods）**：
- 入排标准（与 Protocol 一致）
- 检索策略（完整检索式放入附录）
- 筛选流程（PRISMA Flow Diagram）
- 质量评估方法
- 数据提取变量
- 分析方法（描述性 vs 荟萃分析）

**结果（Results）**：
- PRISMA Flow Diagram 描述
- 研究特征表（每项研究的特征摘要）
- 偏倚风险评估结果
- 主要结局综合结果（表格 + 叙述）
- 亚组分析 / 敏感性分析（如有）

**讨论（Discussion）**：
- 主要发现的总结
- 与现有证据的比较
- 局限性（检索完整性 / 质量 / 异质性）
- 证据质量评级（GRADE）
- 对实践的启示
- 对未来研究的建议

**结论（Conclusion）**：
- 简洁回答研究问题

**工具**：
- RevMan（Cochrane 官方软件，用于制作森林图 + 偏倚风险图）
- R / Stata（荟萃分析统计软件）
- GRADE profiler（证据质量评级）

**耗时**：2–4 月（撰写）

**心法**：
- 方法部分必须足够详细——读者要能根据描述重复你的研究
- 荟萃分析不是必须的——如果研究异质性太高（I² > 75%），描述性综合更合适

---

### 阶段 5：修订（Revision — PRISMA 核对 + 同行评审）

**输入**：
- 初稿

**输出**：
- 修订稿
- PRISMA 2020 核对完成确认

**PRISMA 2020 核对（27 项清单）**：

**标题与摘要（Title & Abstract）**：
- [ ] 标题清楚标明为系统综述
- [ ] 结构化摘要含：背景 / 目的 / 数据来源 / 纳入研究 / 结果 / 局限性 / 结论 / 注册号

**引言（Introduction）**：
- [ ] 研究原理（有研究空白支撑）
- [ ] 研究目的（清晰 PICO 问题）

**方法（Methods）**：
- [ ] 入排标准与研究问题匹配
- [ ] 检索策略完整（所有数据库 + 日期 + 语言限制）
- [ ] 检索策略放入附录
- [ ] 研究筛选流程描述（两人独立 + 冲突解决）
- [ ] PRISMA Flow Diagram 呈现
- [ ] 质量评估方法明确
- [ ] 数据提取变量列出
- [ ] 分析方法描述（描述性 vs 荟萃分析）

**结果（Results）**：
- [ ] 检索结果总数（每数据库分开报告）
- [ ] 去重后数量
- [ ] 每步排除数量 + 原因
- [ ] 纳入研究特征描述
- [ ] 偏倚风险结果呈现
- [ ] 结局数据综合结果

**讨论（Discussion）**：
- [ ] 主要发现总结
- [ ] 证据质量讨论（GRADE）
- [ ] 局限性（检索/发表偏倚/异质性）
- [ ] 对实践/研究的启示

**其他**：
- [ ] 资金来源披露
- [ ] 利益冲突披露
- [ ] 注册号 / 协议引用

**同行评审**：
- 统计专家评审（荟萃分析部分）
- 领域专家评审（临床/实践意义）
- 图表明细核查（数字一致性）

**耗时**：2–4 月

**心法**：
- PRISMA 核对不是可选项——它是系统综述发表的最低规范
- 荟萃分析的统计结果必须经过敏感性分析验证稳健性

---

### 阶段 6：编辑（Editing — 格式与规范）

**输入**：
- 修订稿

**输出**：
- 终稿（符合目标期刊格式）

**引文规范选择**：

| 规范 | 适用领域 | 核心特点 |
|------|----------|----------|
| APA 7th | 心理学 / 教育学 / 社会学 | 作者-年份制；文末字母序参考列表 |
| MLA 9th | 人文 / 文学 | 页内引用；标题引用 |
| Chicago 17th | 历史 / 人文（注释型）/ 管理学 | 脚注/尾注；或作者-年份制 |
| Vancouver | 医学 / 生物医学 | 编号引用；参考列表按出现顺序 |

**引文管理工具**：
- Zotero（开源 + Web Connector）
- EndNote（机构常用）
- Mendeley（Elsevier）

**语言规范**：
- 避免"我认为"——用"本综述发现"
- 主动语态（越来越多的期刊接受或偏好）
- 缩写首次出现全写
- 数字规范（10 以上用阿拉伯数字 vs 统计数据全程阿拉伯数字）

**耗时**：1–2 月

**心法**：
- 不同期刊有不同的格式要求——投稿前必须下载目标期刊的 Author Guidelines 对照检查
- 系统综述的语言要求比普通研究论文更高——避免模糊表述

---

### 阶段 7：发布（Publication）

**输入**：
- 终稿

**输出**：
- 投稿
- 同行评审回复
- 出版

**系统综述目标期刊**：

| 期刊 | 影响因子 | 特点 |
|------|----------|------|
| Cochrane Database of Systematic Reviews | 高（ Cochrane 体系）| 系统综述金标准；需严格遵守 Cochrane 手册 |
| BMJ / Lancet / JAMA | 极高 | 接受高质量系统综述；需临床意义 |
| Journal of Clinical Epidemiology | 高 | 系统综述方法论导向 |
| PLOS ONE | 中高 | 开放获取；接受方法论规范的系统综述 |
| 管理学期刊（如 AMJ / ASQ）| 高 | 接受系统综述；偏重理论贡献 |

**投稿材料清单**：
- Cover Letter
- 稿件（符合期刊格式）
- PRISMA Flow Diagram（单独文件或嵌入稿件）
- 附录（完整检索策略）
- 协议注册确认函
- 利益冲突声明
- 资金来源声明

**耗时**：3–12 月（审稿周期）

**心法**：
- 系统综述的价值在于被引用——选择一个高曝光平台比发表速度更重要
- 定期更新：系统综述需要定期更新（Cochrane 要求每 2 年评估是否需要更新）

## 三、最大痛点清单

| # | 痛点 | 应对 SOP |
|---|------|----------|
| P1 | 文献检索漏掉关键研究 | 检索策略由图书馆员审核；引用追溯法（snowballing）；PRISMA Flow Diagram 透明记录 |
| P2 | 引用管理混乱（几百篇文献） | Zotero 分组管理；每篇文献附标签（P/I/C/O 各维度）；提取数据时同步填写 Zotero 备注字段 |
| P3 | 异质性过高无法做荟萃分析 | 预建亚组分析框架（提前按干预类型/人群/结局分组）；I² > 75% 时改用描述性综合 |
| P4 | 偏倚风险评估主观性 | 使用标准化工具（ROB2 / Newcastle-Ottawa）；两人独立评估 + Cohen's Kappa 报告一致性 |
| P5 | 跨学科整合（管理学跨多个子领域） | 建立跨学科术语对照表；使用宽泛检索词捕获所有相关文献；最终用叙述性框架整合而非强行荟萃 |
