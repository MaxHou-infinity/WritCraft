## 定位（一句话）

Ulysses 是 Apple 生态中最受推崇的极简 Markdown 写作工具，以"12根手指、25小时"的理念，为每日大量写作的人提供无干扰、高效率的写作体验。

---

## 目标用户

- 专业作家（每日大量写作）
- 博主、内容创作者
- 学者、学生（论文写作）
- 技术写作者（Markdown 原生）
- 出版写作（电子书/PDF）

---

## 核心3大功能

### 1. 极简 Markdown 编辑器

全程键盘操作，无需鼠标，支持 Markdown 实时预览。Markup-based 界面让手指无需离开键盘，提升打字流畅度。

### 2. 库（Library）项目管理

所有文本集中存储于 Ulysses 的 Library，支持文件夹层级组织，可按标签、关键词、状态（草稿/完成）筛选。

### 3. 一键发布（Publishing）

直接发布到 WordPress、Ghost、Medium、Micro.blog，也支持导出为 PDF、Word、ePub、纯文本。

## 优缺点

### 优点

1. **Apple 设计奖得主**：UI 设计精良，极简无干扰，真正"写作时感觉不到软件存在"
2. **Markdown 原生**：完全基于 Markdown 设计，无格式负担，输出干净纯文本
3. **发布生态完善**：直连 WordPress、Ghost、Medium，减少发布摩擦
4. **iCloud 同步流畅**：Apple 全平台无缝同步，离线可用
5. **专注长文**：Library 项目管理适合大型写作项目（书稿、长篇连载）

### 缺点

1. **AI 能力弱**：相比 Notion AI 和 Lex，Ulysses AI 功能极其基础
2. **纯 Apple 生态**：无 Windows/Web 版本，跨平台用户无法使用
3. **无实时协作**：单用户工具，无法团队实时共同编辑
4. **无大纲/卡片视图**：长文结构管理不如 Scrivener
5. **订阅制**：无买断选项，长期使用成本高于 Ulysses

## 对 WritCraft 的借鉴点

1. **极简 Markdown 设计**：Ulysses 的" Markup-based editor"理念值得借鉴——让手指不离开键盘是写作效率的关键
2. **发布工作流**：WritCraft 可以内置"一键发布"到各平台，减少发布摩擦
3. **写作目标系统**：每日字数目标 + 截止日期 + 统计面板，帮助写作者建立写作习惯
4. **Library 项目管理**：多层级文件夹 + 标签 + 状态管理，适合组织大量写作项目
5. **家庭/团队共享模式**：通过 iCloud 家庭共享实现轻量级"协作"（只读或共享库）
