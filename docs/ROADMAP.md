# 笔触公开路线图

笔触的目标不是生成更多文字，而是帮助专业作者完成更长、更复杂、也更可信的作品。

路线图表达方向，不构成发布日期或功能承诺。每个阶段只有通过真实作者验证后才会进入下一阶段。

## Preview：证明完整写作闭环

当前重点：

- 项目、文件、段落三级 AI 协作；
- `edit.md` 项目意图与分区上下文；
- Plan → Changes → 差异审阅 → History；
- 来源、研究、插图与一致性图谱；
- macOS npm Developer Preview 的稳定安装与恢复；
- 使用真实、隔离的长文项目完成作者验收。

## V1：成为每天可以使用的个人写作工具

计划方向：

- 更顺滑的安装、升级与首次启动；
- 更稳定的长项目性能和错误恢复；
- 更成熟的章节导航、检索和图谱交互；
- 可理解的模型、额度和费用提示；
- 更完整的导入、导出与备份体验。

## Pro：为严肃创作提供付费能力

可能进入付费方案的能力：

- 更大的长文上下文与跨项目知识；
- 专业研究、引用核查和证据工作流；
- 高级一致性检查与长期项目记忆；
- 多模型选择、调用预算和费用治理；
- 专业模板、诊断、恢复与优先支持。

具体定价会在真实作者验证后公布。当前 Preview 不承诺未来免费额度或升级权益。

## Team：让创作团队保持同一套事实

长期探索：

- 编辑、作者与研究人员的角色边界；
- 可审计的审阅、批准和版本流转；
- 团队术语、事实与引用资产；
- 企业级安全、权限和私有部署选择。

## 不会改变的原则

无论免费还是付费版本：

- 作者拥有自己的作品；
- AI 修改必须可见、可拒绝、可追溯；
- 不用模糊的自动化掩盖事实与来源；
- 不把重要写作项目锁进不可迁移的专有格式；
- 新能力必须先证明安全、可恢复，再扩大范围。

欢迎通过 GitHub Issue 分享你最希望解决的写作难题。真正高频、清晰且能被验证的问题，会优先进入路线评估。
