# WritCraft v0.1.1 Developer Preview

这一版把近期真实作者体验中最影响使用判断的交互问题，正式带到公开 Preview。

## 亮点

- 项目卡提交现在显示真实等待状态，并用普通用户能理解的方式解释失败。
- 长文编辑区拥有独立、始终可见的纵向滚动能力。
- Changes 审阅明确区分“选择接受/拒绝”和“确认写入磁盘”，决定完成后不再常驻旧按钮。
- 项目卡入口移动到左侧活动栏；初始化第二阶段使用更清晰的任务说明和按钮层级。
- 文件、搜索、来源与一致性星图统一为一个工作区导航状态，不再出现混合侧栏或切不回图谱。
- “新建项目 / 打开项目”收纳到项目标题的 `•••` 菜单，空项目欢迎页仍保留首次入口。
- 活动栏改用可访问 SVG 图标，并补充键盘焦点、悬停说明和窄屏适配。

## 安装

```bash
npx writ-craft@preview
```

环境检查：

```bash
npx writ-craft@preview --check
```

需要 macOS 12 或更高版本、Node.js `>=22.12.0`，以及 npm 10 或 11。

## Preview 边界

这是采用专有评估许可证的开发者预览版，不是稳定版或生产授权。请先备份写作项目，再使用副本体验。合格真实作者项目验收仍未完成；个别既有项目的一致性星图缓存可能显示文件系统错误，已作为独立问题登记。
