# 历史产品交付物归档

本目录保存 WritCraft 早期调研、竞品矩阵、HTML 报告、产品价值说明和一个月 V0 计划，仅用于追溯产品判断如何形成。

> 状态：**全部为历史快照，不得作为当前需求、实现事实、版本排期、测试证据或续作入口。**

目录内材料包含后来已经改变的假设，例如小说用户范围、TipTap、旧 Diff 形态、模型能力、图片 Key 前缀、旧测试总数和早期 28 天排期。保留这些内容是为了复盘，不代表当前产品承诺。

当前权威入口：

- 产品必须做什么：`../docs/WRITCRAFT-PRD-V3.md`
- 下一版本做什么：`../docs/ROADMAP.md`
- 当前实际完成到哪里：`../v0/DEVELOPMENT-STATUS.md`
- 当前版本如何验收：`../docs/*-CONTRACT.md`
- 当前产品版本：`../v0/package.json`

任何历史交付物与上述文件或当前源码冲突时，以当前源码、可复现证据及上述权威文件为准，不修订历史正文来伪装当时判断。
